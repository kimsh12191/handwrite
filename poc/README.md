# PoC — 검증용 스크립트

둘 다 **실행 확인 완료**. 의존성: numpy 만.

## `skeleton_style_poc.py`

`plan.md` 의 핵심 가정을 검증한다: **글자 = 스켈레톤(무엇을) × 스타일 파라미터(어떻게)**

```bash
python poc/skeleton_style_poc.py
```

확인되는 것 (ASCII 플롯으로 출력):
- **검증 A** — 스켈레톤이 있으면 읽을 수 있는 숫자·한글 자모가 나온다
- **검증 B** — 같은 텍스트 + 다른 스타일 파라미터 = 다른 필체 (기울임 / 떨림 / 납작+흘림)
- **검증 C** — 스타일 파라미터를 고정하면 **다른 텍스트도 같은 필체로** 나온다 ← 프로젝트의 목표 동작

139줄. Phase 0 (관문 실험) 의 출발점으로 쓴다.

**아직 없는 것**: ΣΛ 속도 모델, 잉크 렌더링, 획 겹침, 인스턴스별 파라미터 지터.
Phase 1 에서 채운다. 이건 가정 검증용이지 시뮬레이터가 아니다.

## `v1_failure_evidence.py`

폐기된 v1 (`simulator/dynamics.py`, 커밋 `6edb3d1`) 이 왜 글자를 못 그리는지에 대한 실측 증거.

```bash
python poc/v1_failure_evidence.py
```

출력: $x(t)$ 와 $y(t)$ 의 상관계수가 정확히 1.0, $\max|x-y| = 0.0$ → 궤적이 $y=x$ 직선에 갇힘.
같은 실수를 반복하지 않기 위해 남겨둔다.
