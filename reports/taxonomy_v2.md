# Writer parameter space v2 — 전체 설계

v1(`taxonomy_v1.md`)은 **이 저장소에서 직접 측정된 축만** 담았다. 그래서 파라미터가
사실상 3개였고, "손글씨와 개인의 습관을 표현하는 공간"으로는 두 자릿수 이상 모자랐다.
규칙(HANDOFF §2)은 지켰지만 목표를 못 맞춘 상태다.

v2는 **필요한 공간 전체**를 설계한다. 근거의 출처가 서로 다르므로 항목마다 등급을 단다.

| 등급 | 뜻 |
|---|---|
| `[측정]` | 이 저장소에서 실제 코퍼스로 측정함. 수치는 `phase2_findings.md` |
| `[문헌]` | 검증된 선행 모델을 채택. 상상해서 만든 축이 아님 |
| `[설계]` | 구조상 필요하다고 판단한 축. **아직 검증 안 됨 — 측정으로 확정해야 함** |

`[설계]`가 많은 것은 정상이다. 그것이 곧 남은 할 일 목록이다.
중요한 것은 **빈칸을 비워 두지 않고 무엇이 들어가야 하는지를 먼저 적어 두는 것**이다.
빈칸으로 두면 다음 사람이 그 층이 필요 없다고 오해한다.

---

## 0. 이 공간이 갖춰야 할 성질

설계에 들어가기 전에, 최종 목표(HANDOFF §14)가 요구하는 성질을 먼저 못박는다.

1. **개인 동일성** — 한 사람의 서로 다른 문장에서 같은 θ가 나와야 한다
2. **매번 다름** — 같은 θ로 같은 글자를 두 번 쓰면 **달라야** 한다.
   폰트·GAN의 실패는 변동이 작은 게 아니라 0이라는 것이다
3. **미관측 문자 생성** — 그 사람이 한 번도 안 쓴 글자도 만들 수 있어야 한다
4. **해석 가능성** — 축에 사람이 읽을 수 있는 이름이 붙어야 한다

2번이 v1에 완전히 빠져 있었다. **분산 자체가 개인 파라미터다.** 어떤 사람은
일관되게 쓰고 어떤 사람은 들쭉날쭉하다. 평균만 모델링하면 그 사람이 아니다.
이 요구 때문에 아래 모든 층에 "평균"과 "변동" 두 벌이 필요하고, 파라미터 수가
사실상 두 배가 된다.

3번 때문에 공간은 **음절이 아니라 자모/획 단위**여야 한다. 11,172 음절을 개별로
저장하면 미관측 문자를 못 만든다.

## 1. 층 구조

```text
L0  primitive        획 원형 (직선/호/루프/훅/점)          — 스크립트 공용
L1  stroke           획 하나의 기하                        — 8 numbers/획
L2  relation         획끼리 어떻게 붙는가                  — 이산 + 연속
L3  jamo shape       자모별 형태 (모집단 평균 + 개인 편차)  — PCA 모드
L4  allograph        이체 선택                             — 이산
L5  composition      자모 → 음절 배치                      — 한글 고유
L6  line / page      자간·베이스라인·기울기·크기 드리프트
L7  motor            타이밍·속도·펜 들림                    — 온라인 데이터 필요
L8  brush            굵기·필압·잉크
L9  variability      위 전부의 분산·상관·드리프트           ← 매번 다름을 담당
```

L9는 별도 층이 아니라 **L1~L8 각각에 붙는 두 번째 벌**이다. 따로 적는 이유는
v1에서 통째로 빠졌기 때문이다.

## 2. L0 — 획 원형 `[문헌]`

HANDOFF §6이 요구한 shape family가 여기다. 스크립트를 가로질러 재사용된다.

| primitive | 한글 | 라틴/숫자 |
|---|---|---|
| 직선 | ㅣ ㅡ ㄱ의 변 | I l 1 |
| 호 (열림) | ㅅ의 다리, ㅈ | C U n |
| 루프 (닫힘) | ㅇ, ㅁ, ㅂ | O 0 o a e d 6 8 9 |
| 꺾임 (코너) | ㄱ ㄴ ㄷ ㄹ | L V A K 4 7 |
| 훅 / 종단 | ㅎ의 꼭지, ㅊ | j y g의 꼬리 |

이것이 참이면 **ㅇ과 O와 0은 같은 primitive의 다른 파라미터**이고, 숫자에서
검증한 루프 파라미터가 한글 ㅇ에 그대로 전이된다. 그래서 숫자/영문을 먼저 하는
것이 싸다(이전 계획의 "숫자가 쉬운 승리"와 같은 결론).

**미검증.** EMNIST/UJI가 막혀 아직 확인 못 했다.

## 3. L1 — 획 하나의 기하 `[문헌]`

두 가지 표현이 있고, 둘 다 검증된 모델이다.

**(a) ΣΛ 원호** — 획 = 단일 원호. 파라미터 `D, θs, θe` (3개).
운동학 이론에 근거가 있고 극도로 압축적이다. 단 획 하나가 원호 하나라
복잡한 획은 여러 개로 쪼개야 한다.

**(b) 스플라인 제어점** — BPL(Lake et al. 2015)이 쓰는 방식.
sub-stroke마다 제어점 ~5개 → 10 numbers.

실무적 절충: **획 = 원호 1~3개의 연결**, 획당 약 **8 numbers**.

한글 원자 자모 24개(자음 14 + 모음 10; 쌍자음·복합모음·겹받침은 조합)의
획 수는 평균 약 2.4개다.

```text
ㄱ1~2  ㄴ1~2  ㄷ2~3  ㄹ3  ㅁ3~4  ㅂ4  ㅅ2  ㅇ1
ㅈ2~3  ㅊ3~4  ㅋ2~3  ㅌ3  ㅍ4   ㅎ3
ㅏ2 ㅑ3 ㅓ2 ㅕ3 ㅗ2 ㅛ3 ㅜ2 ㅠ3 ㅡ1 ㅣ1
```

→ 한글 인벤토리 **약 58획**. 평균 골격만 해도 58 × 8 ≈ **464 numbers**.

이 464는 개인 파라미터가 아니라 **모집단 평균**이다. 개인은 여기서의 편차만
가진다(L3).

## 4. L2 — 획끼리 붙는 방식 `[문헌]`

BPL의 핵심 아이디어이고, v1에 완전히 없던 층이다.
획 i+1이 어디서 시작하는지를 **관계**로 적는다.

| 관계 | 파라미터 |
|---|---|
| independent | 절대 위치 (2) |
| attached to start / end of 획 i | 대상 획 index (이산) |
| along 획 i at position τ | index + τ ∈ [0,1] |

이산 선택 + 연속 위치의 **혼합**이다. 이게 중요한 이유:
`ㅏ`의 가로획이 세로획의 **어디에** 붙는지가 개인차의 큰 부분이고,
그 값은 좌표가 아니라 **비율 τ**로 저장해야 크기가 바뀌어도 유지된다.

획 접합부마다 약 **3 continuous + 1 categorical**.

## 5. L3 — 자모 형태: 모집단 평균 + 개인 편차 `[설계]` ← 핵심

여기가 **"각 자음·모음의 파라미터 공간"** 이라는 원래 질문의 답이 놓일 자리다.

```text
자모 j 의 형태 = 모집단 평균 골격 x̄_j  +  Σ_k  b_jk · φ_jk
                                          ↑ 개인 계수   ↑ 변동 모드
```

`φ_jk`는 실제 데이터에서 나와야 하는 변동 모드다. 이걸 얻는 표준 절차가
**PDM / Active Shape Model**(Cootes & Taylor 1995)이고, 순서가 정해져 있다.

```text
골격 추출 → 점 대응(correspondence) → Procrustes 정렬 → PCA
```

**대응 단계가 필수다.** 대응 없이 PCA를 돌리면 분산이 형태가 아니라 어긋남에
쓰인다 — 이 저장소에서 이미 그 증상을 측정했다 `[측정]`.
PC1~PC4가 전부 획 양옆의 빨강·파랑 쌍(획이 밀린 것)이었고, 80% 분산에 28성분이
필요했다. v1에서 "자모 분할이 병목"이라고 쓴 것은 절반만 맞았다.
필요한 것은 분할이 아니라 **골격 위의 점 대응**이며, 분할은 그 수단이다.

**자모당 모드 수 K_j 는 아직 모른다.** 그것이 이 프로젝트가 측정해야 할 바로
그 수다. 예상 범위 5~10.

- K=6이면 개인 형태 계수 = 24 자모 × 6 ≈ **144**
- 초성/종성 역할 분리가 필요하면(아래) 더 늘어난다

**역할 분리가 필요하다** `[측정]`. 종성이 붙을 때 위쪽이 눌리는데, 그 눌림의
2/3만 수직 압축 하나로 설명되고 1/3이 남는다(잔차가 코퍼스 잡음의 8~10배).
즉 같은 ㄱ이라도 초성일 때와 종성일 때 형태 계수를 공유하면 안 된다.
자주 쓰이는 자모는 역할별로 따로 두어야 한다.

### 성공 판정 기준을 미리 못박는다

대응을 붙인 뒤 `scripts/shape_space.py`를 다시 돌린다.
현재 28성분이 **크게 떨어지지 않으면 대응이 실패한 것**이다.
눈금은 이미 검증돼 있다 — `scripts/basis_control.py`가 선언 4-DOF 합성군을
4성분으로 읽는다 `[측정]`. 사후 해석의 여지 없이 미리 정해둘 수 있는 기준이다.

## 6. L4 — 이체(allograph) 선택 `[설계]`

**이 공간은 순수 연속이 아니다.** v1이 놓친 구조적 사실이다.

어떤 사람의 `4`는 열려 있고 어떤 사람은 닫혀 있다. `ㅁ`을 2획으로 쓰는 사람과
3획으로 쓰는 사람이 있다. 이건 연속 파라미터를 아무리 흔들어도 넘어갈 수 없는
**위상(topology)의 차이**다.

| 파라미터 | 형태 |
|---|---|
| 자모별 이체 선택 | categorical |
| 이체 혼용 비율 | 연속 (한 사람이 두 형태를 섞어 쓰기도 한다) |

자모당 약 1 categorical + 1 continuous → **약 48**.

혼용 비율이 필요한 이유: 사람은 같은 글자를 늘 같은 이체로 쓰지 않는다.
이것도 "매번 다름"의 일부다.

## 7. L5 — 자모 → 음절 배치 (한글 고유) `[측정]` + `[설계]`

한글은 조합형이므로 배치가 별도 층이다. 배치형은 6가지다
(중성 부류 3 × 종성 유무 2).

| 파라미터 | 등급 | 값 |
|---|---|---|
| `jong_compression` — 종성이 있을 때 초성+중성이 쓰는 세로 비율 | `[측정]` | 평균 0.70 (p10 0.55 ~ p90 0.85) |
| 위 값의 중성 부류 의존 | `[측정]` | horizontal 0.67 < vertical 0.71 < mixed 0.78, 두 코퍼스 순서 동일 |
| 배치형별 초성/중성/종성 박스 (x, y, w, h) | `[설계]` | 6형 × 3요소 × 4 ≈ 72 |
| 요소 간 겹침 / 침범 허용량 | `[설계]` | 흘려 쓸수록 커진다 |

개인 편차는 72개 전부가 아니라 그 위의 저차원 보정(≈ **20**)으로 충분할 것으로
본다 — `[설계]`, 측정 필요.

v1이 가진 축은 사실상 이 표의 첫 두 줄뿐이었다.

## 8. L6 — 줄과 페이지 `[문헌]` + `[설계]`

| 파라미터 | 비고 |
|---|---|
| 자간 평균 / 분산 | |
| 어간 평균 / 분산 | |
| baseline drift 진폭 + **상관 길이** | 저주파. Perlin/simplex 노이즈 |
| 전역 기울기(slant) 평균 / 분산 | |
| 글자 크기 평균 / 분산 / 페이지 내 드리프트 | 피로·워밍업 |
| 줄 기울기 | |
| tremor (고주파 떨림) | 고령·장애 필기의 지배적 사실감 단서 |

약 **15**.

> **상관 길이**가 핵심이다. 문자마다 독립으로 흔들면 페이지 전체가 균질해져
> 오히려 티가 난다. 인접 문자가 상관돼야 사람처럼 보인다.

**현재 데이터로 측정 불가** `[측정 불가]`. PE92·SERI95는 문자 단위로 미리
잘려 있어 페이지 문맥이 없다. 다른 데이터가 필요하다.

## 9. L7 — 모터 `[문헌]`

온라인 궤적이 있어야 열린다. ΣΛ(Plamondon)가 검증된 모델이고, 파라미터의
개인/내용 분리까지 이론적으로 제공한다.

| 파라미터 | 분류 | 비고 |
|---|---|---|
| μ (로그 시간지연) | **개인** | 신경근 응답 지연. 비교적 안정 |
| σ (로그 응답시간) | **개인** | 속도 종모양의 비대칭. 피로·노화에 민감 |
| D, θs, θe | **내용** | 무엇을 쓰는가 |
| t₀ | 시퀀싱 | 획 겹침을 만든다 |
| 획 겹침 분포 | **개인** | 겹침 0 = 로봇, 큼 = 빠른 흘림. 가장 표현력 있는 노브 |
| 코너 감속 이득 | **개인** | |
| 오버슛 경향 | **개인** | |
| 획 순서 / 펜 들림 패턴 | **개인**, 이산 | |

개인 파라미터 약 **15** + 획 순서(이산).

> ΣΛ의 (μ,σ) = 스타일 / (D,θs,θe) = 내용 분리는 이 프로젝트가 원하는
> "스타일 vs 내용" 분해를 **이론적으로 정당화**해 준다. 자의적 설계가 아니다.

**AI-Hub 71307 대기.** HANDOFF §7대로 offline 이미지에서 역추정하지 않는다.

| 파라미터 |
|---|
| 기준 굵기 |
| 굵기–속도 결합 (빠를수록 얇아짐) |
| 필압 응답 곡선 |
| 불투명도 |
| 가장자리 부드러움 |
| 종단·감속 지점 잉크 고임 |

약 **8**.

주의 `[측정]`: 이전 v3 실험에서 **굵기가 목적함수를 지배해 형태를 이겼다**
(실제보다 2배 굵은 획이 실제에 가까운 굵기를 거리 기준으로 이김).
브러시는 표현력에는 싸게 기여하지만 **피팅 목적함수에는 독**이다.
형태 거리와 굵기 거리를 반드시 분리해야 한다.

## 11. L9 — 변동 구조 ← "매번 다름"을 담당 `[설계]`

v1에 통째로 없었고, 요구사항 2번을 혼자 책임지는 층이다.

| 파라미터 | 왜 필요한가 |
|---|---|
| 각 형태 계수의 분산 | 이 사람이 얼마나 일관된가. **일관성 자체가 개인 서명이다** |
| 계수 간 공분산 | ㄱ이 넓게 나온 날 ㅏ도 넓은가 |
| 음절 내 상관 | 초성이 크면 종성이 작아지는 보상 |
| 문자 간 자기상관 / 드리프트 | 페이지 내 피로·적응 |
| 이체 전환 확률 | 언제 다른 형태로 갈아타는가 |

**전역 파라미터만 흔드는 것으로는 부족하다** `[측정]`.
전역 affine + 굵기(4~5 DOF)는 같은 척도에서 4~5성분으로 읽히는데,
실제 한 음절 클래스 내부 변동은 28성분이다. 즉 변동이 **골격 층에도** 있다.
같은 도장을 다르게 찍는 것이 아니라 매번 다시 그리는 구조여야 한다.

섭동은 계수에 직접 주기보다 **목표점 단위**로 주는 편이 가독성 보존에 유리하다
`[문헌]` — 동역학이 아니라 기하를 건드리기 때문.

분산 파라미터 수는 평균 파라미터와 같은 규모(대각만 쓰면 동수, 저차원 상관을
더하면 +α). 약 **150~300**.

## 12. 예산 합계

한글 기준, 개인 파라미터 θ_writer:

| 층 | 연속 | 이산 | 등급 |
|---|---|---|---|
| L3 자모 형태 계수 (24 자모 × ~6 모드) | ~144 | | `[설계]` K 측정 필요 |
| L3′ 역할 분리분 (빈출 자모 초성/종성 분리) | ~40 | | `[측정]`으로 필요성 확인됨 |
| L4 이체 | ~24 | ~24 | `[설계]` |
| L5 배치 개인 보정 | ~20 | | `[측정]` 2개 + `[설계]` |
| L6 줄/페이지 | ~15 | | `[문헌]` / 측정 불가 |
| L7 모터 | ~15 | 획순 | `[문헌]` / 데이터 대기 |
| L8 브러시 | ~8 | | `[설계]` |
| L9 변동 구조 | ~150–300 | | `[설계]` |
| **합계** | **약 420–570** | **약 50** | |

여기에 **모집단 공용**(개인 파라미터가 아님)으로 평균 골격 인벤토리 ~464와
배치형 규칙 ~72가 따로 있다.

v1은 이 중 **3개**를 가지고 있었다.

두 가지를 강조한다.

1. **개인/공용 분리가 한 장 피팅을 가능하게 한다.** 464개 평균 골격은
   코퍼스에서 한 번 구하면 끝이고, 개인에게서 추정할 것은 그 위의 편차뿐이다.
   이 분리가 없으면 한 사람당 수백 장이 필요해진다.
2. **연속만이 아니다.** 이체·획순·획수는 이산이고, 연속 최적화로는 원리적으로
   넘어갈 수 없다. 탐색 구조가 층에 따라 달라야 한다.

## 13. 이 설계가 v1과 다른 점

| | v1 | v2 |
|---|---|---|
| 파라미터 수 | 3 | ~470–620 |
| 변동 구조 | 없음 | L9 (요구사항 2번 담당) |
| 이산 축 | 없음 | 이체·획순·획수 |
| 획/자모 층 | 없음 ("잔차가 남는다"만) | L1~L3 |
| 모터 | 비워 둠 | ΣΛ 채택, 개인/내용 분리 |
| 근거 없는 축 처리 | 삭제 | 등급을 달아 남김 |

마지막 줄이 태도의 차이다. v1은 근거 없는 축을 지웠고, v2는 **등급을 달아
남긴다.** 지우면 다음 사람이 그 층이 필요 없다고 오해한다.

## 14. 다음 한 걸음

L3의 대응 단계가 전체의 병목이다. 그것만 열리면 L1·L2·L3·L4가 같이 열리고,
K_j(자모당 모드 수)가 나오면 위 예산의 가장 큰 항이 추정치에서 측정치로 바뀐다.

판정 기준은 이미 손에 있다: **28성분이 몇으로 떨어지는가.**
